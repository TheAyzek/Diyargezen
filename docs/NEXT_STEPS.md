**Son Güncelleme:** 2026-06-07
**Desteklenen Sistemler:** D&D 5e, Pathfinder 1e, M&M 3e

---

## MVP Odak (Pazartesi)

- ETL pipeline (`run_etl.py`) — JSON → SQLite entities
- PySide6 GUI (The Tavern / The Forge / Character Sheet)
- Soft validation + homebrew onayı
- PDF export (ReportLab)

- 3 TTRPG sistemi (D&D 5e, Pathfinder 1e, M&M 3e)
- Adım adım karakter oluşturma sihirbazı
- SQLite karakter depolama
- PDF ve HTML export
- Homebrew içerik yöneticisi
- Encounter tracker
